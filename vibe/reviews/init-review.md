## Architecture Drift Detection

### 🔴 DRIFT-001 — SCSS/CSS Source Drift (P0)

**Decision**: "scss/style.scss is intended source for main custom CSS" — ARCHITECTURE.md §Styling Pattern

**Found**: `css/style.css` (994 lines) contains extensive rules absent from `scss/style.scss` (828 lines):
- `.services-meta`, `.meta-card`, `.meta-label`, `.meta-value`, `.meta-link` (lines 523-555 of CSS)
- `.services-cta` (line 559)
- `.services-grid` (line 568)
- `.services-showcase` (lines 574-583)
- `.service-card` and variants (lines 589-621)
- Additional selectors in `.site-service-item` grouping

Running `npm run build` will overwrite `css/style.css`, **destroying** all these production-only styles.

**Impact**: High — breaks the Services section visual design entirely. Blocks HP-03 through HP-06.

**Fix**: HP-01 (already planned). Merge missing production CSS rules into SCSS source before any rebuild.

### 🔴 DRIFT-002 — Navbar Anchor Mismatch (P0)

**Decision**: Section IDs should be targetable from navbar — ARCHITECTURE.md §Known Architectural Risks

**Found**: `index.html:63-64` navbar links target `#section-work-experience` and `#section-organization`, but actual section IDs are:
- `#section-resume` (line 175)
- `#section-oe` (line 436)

**Impact**: Two main navigation links are broken. Users clicking "Work Experience" and "Organization" land nowhere.

**Fix**: HP-02 (already planned).

### ⚠️ DRIFT-003 — Google Fonts Double-Load (P1)

**Decision**: Performance optimization — ARCHITECTURE.md §Performance

**Found**: `index.html` loads Google Fonts twice:
- Lines 19-26: `rel="preload"` pattern (Nunito+Sans + Inter)
- Lines 42-43: Regular `<link rel="stylesheet">` (Nunito+Sans + Inter, same URLs)

Both sets resolve to the same fonts. The preload pattern at lines 21-25 already handles JS-enabled browsers. Lines 42-43 are redundant and cause duplicate network requests.

**Impact**: Unnecessary bandwidth usage, potential FOUC from two competing load signals.

**Fix**: Remove lines 42-43 (redundant stylesheet links).

### ⚠️ DRIFT-004 — Duplicate Footer Copyright (P1)

**Decision**: Template attribution should be preserved — CLAUDE.md §Boundaries

**Found**: `index.html:917-918` contains two nearly identical copyright lines with only class differences (`underline-link text-primary` vs `text-primary`). Users see "Copyright © ... All rights reserved" printed twice.

**Impact**: Visual duplication in production footer.

**Fix**: Remove line 918 (duplicate with less specific classes).

### ℹ️ DRIFT-005 — server.js Static Root Mismatch (P2, known)

**Decision**: server.js should serve the site locally — ARCHITECTURE.md §Known Architectural Risks

**Found**: `server.js:7` sets `PUBLIC_DIR = path.join(__dirname, "public")` but no `public/` directory exists. `npm start` serves nothing or errors.

**Impact**: Local Express server is non-functional.

**Fix**: Change `PUBLIC_DIR` to `__dirname` (repo root) or create symlink. Not blocking for feature work since `python -m http.server 8000` works.
